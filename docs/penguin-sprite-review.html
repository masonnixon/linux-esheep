Nine Penguins for the Flock

Nine procedurally-drawn 40×40 pixel-art penguins, built at the same tile scale and outline weight as the eSheep sprite sheet so whichever one you pick can drop straight into the same engine. Walk cycle shown, 3 frames each — hover a card to feel the strut. A–C is the original pass, D–F pushes cartoony/mascot, and G–I (bottom) are three more takes on Glossy Classic (D), the pick so far.

The straight read: near-black body, bright white belly, orange beak and feet, no extra ornament. Closest to the actual Linux mascot silhouette — lowest risk, instantly recognizable, but the least distinct from a hundred other penguin icons.

Baby Tux

I — Glossy Classic, younger build
40×40 px / frame 3 frames

Same gloss and cross-eyed expression as Glossy Classic, dialed toward a chick: head scaled up another 12%, body softened from black to a warm charcoal-grey like real penguin down. Leans extra-cute without introducing any new rig element.

bigger headsofter charcoal downsame rig as D

Method — drawn with PIL at 4x internal resolution using hard-edged primitives (no anti-aliasing), then downsampled with nearest-neighbor to 40×40 to bake in the chunky pixel look, matching the eSheep tile grid (16×11 @ 40px).

Status — draft proportions, one pose family (stand / lean-left / lean-right). Once a direction is picked I'll round out a full frame set (turn, sit, sleep, slide) sized for the same animation-graph engine as the sheep.
