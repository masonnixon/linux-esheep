# Ice Blue penguin sprite sheet — coverage notes

`penguin_ice_blue_spritesheet.png` is laid out on the same 16x11 grid (40px
tiles, 640x440) as `sheep_spritesheet.png`, so `esheep_animations[]` frame
indices resolve the same way for either character.

**Full coverage**: every tile index used anywhere across all 54 animations
in `esheep_animations[]` is filled — 110 of the 176 grid cells (the other 66
are simply never referenced by any animation, in the sheep data either).
Generated by `tools/gen_animations.py`'s companion scripts:

- `tools/gen_penguin_cartoon_variants.py` — the base "Glossy Classic" rig
  (gloss highlight, cross-eyed googly stare) that Ice Blue is a recolor of.
- `tools/gen_penguin_sheet.py` — the original Phase-2-scope pass (36 tiles:
  walk, spin, fall, sleep, vertical/top-edge climbing — the animations
  reachable without window/taskbar docking).
- `tools/gen_penguin_sheet_full.py` — fills in the rest: run, jump,
  grooming/reaction closeups, dizzy reactions, the boing bounce
  squash-stretch cycle, catching fire, sooty aftermath, and the black-morph
  gag. Run this one; it regenerates the base 36 first, then adds the rest.

Three tiles are true scene props copied directly from `sheep_spritesheet.png`
rather than redrawn, since they're not the character at all: the water
trough (169, 170, 171 — empty/spilling/full) and the flower growth stages
(149-153). Tile 174 looks adjacent to the flower animation but is actually a
sheep face closeup used as a bookend reaction shot — that one *is* drawn as
a penguin pose, not copied.

Fidelity notes:

- Walk, spin, fall, sleep, run, jump, and the fire/soot/black-morph gag
  sequences are distinct, purpose-drawn poses (procedural PIL primitives,
  not hand-pixeled — see the generator scripts for the exact shapes).
- "Closeup" reaction tiles (dizzy eyes, surprised single-eye zooms) are
  produced by cropping and re-scaling a normal frame rather than drawing a
  separate close-up rig — a cheap trick that reads fine at 40px but won't
  hold up if these are ever displayed larger.
- Vertical/top-edge walking (animations 37-42) still reuses the plain stand
  pose as a placeholder — a real side-on climbing rig hasn't been drawn.

Regenerate with `python3 tools/gen_penguin_sheet_full.py` (run from the repo
root) if the base "Ice Blue" design changes; it's idempotent and rebuilds
the whole sheet from scratch each time.
